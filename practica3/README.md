# Practice 3: Single View Application with Highcharts

## Overview

Practice 3 presents a Single View Application (SVA) designed for academic student management and real-time performance analytics. The system combines full CRUD workflows for student profiles and grade records with modal-embedded Highcharts visualizations. Furthermore, the backend is engineered to handle hybrid request payloads, supporting both traditional url-encoded form data and raw JSON request bodies generated by modern JavaScript frontends.

---

## Architectural Components

* **`webservice/`**: Exposes RESTful endpoints managing student entities and grade evaluations. Incorporates input stream parsing to support requests originating from Fetch API, Axios, or jQuery.
* **`app/`**: Client interface rendering the student catalog, registration/edit forms, and interactive modal dialogs hosting performance charts.

---

## Technical Stack

* **Backend Framework:** CodeIgniter 3.1.x (PHP)
* **Frontend Libraries:** jQuery 3.7.1, Highcharts JS 11.x, Bootstrap 5, FontAwesome 6
* **Data Transport:** JSON over HTTP
* **Database Engine:** MySQL / MariaDB (tables: `alumnos`, `calificaciones`)

---

## Service Endpoints

Located in `webservice/application/controllers/Back.php`:

| HTTP Method | Endpoint | Parameters | Description |
| :--- | :--- | :--- | :--- |
| `GET`, `POST` | `/back/alumnos` | None | Returns all registered students with full names, gender, and age. |
| `POST` | `/back/alumno` | `matricula` | Retrieves complete record for a single student. |
| `POST` | `/back/calificaciones` | `matricula` | Fetches numeric grades across academic evaluation units for a specific student. |
| `POST` | `/back/agrega_alumno` | `matricula`, `appaterno`, `apmaterno`, `nombre`, `sexo`, `edad` | Creates a new student record. |
| `POST` | `/back/modifica_alumno` | `matricula`, `appaterno`, `apmaterno`, `nombre`, `sexo`, `edad` | Modifies existing student data. |
| `POST` | `/back/elimina_alumno` | `matricula` | Cascades deletion of student record and associated grades. |

---

## Key Technical Features

1. **Dual Input Stream Parsing:**
   To accommodate both legacy AJAX callers and modern fetch clients (such as React), the controller evaluates the incoming raw input stream:
   ```php
   if ($this->input->raw_input_stream != "" && $this->input->raw_input_stream[0] == "{") {
       $input = json_decode($this->input->raw_input_stream);
       $matricula = $input->matricula;
   } else {
       $matricula = $this->input->post("matricula");
   }
   ```

2. **Performance Charting Modal:**
   Clicking the analytics action on any student table row invokes an asynchronous call to retrieve grade points. The response instantiates a Highcharts column/line chart dynamically inside a Bootstrap modal window without triggering page reloads.

3. **Client-Side Validation & Feedback:**
   All operations include user feedback via unified toast/modal notification utilities (`mensajes.js`).
